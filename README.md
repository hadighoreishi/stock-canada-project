# Stock Canada Project

Practice NumPy, pandas, and visualization on TSX data.

## Setup
- Python 3.x
- `pip install yfinance pandas numpy matplotlib`

## Notebooks
- 01_download_data.ipynb — fetch TSX prices
- 02_clean_returns.ipynb — tidy data & returns
- 03_charts.ipynb — moving averages, drawdowns

## Roadmap
- Correlations & sector compare
- Simple momentum/backtest
- Dashboard (stretch)
